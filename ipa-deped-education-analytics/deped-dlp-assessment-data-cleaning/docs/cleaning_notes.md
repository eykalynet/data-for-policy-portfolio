# Cleaning Notes

## General Standards

- Raw files in `raw/` are never edited.
- Generated analytic data is saved in `data/`.
- Generated tables, figures, logs, and validation files are saved in `outputs/`.
- R and Stata scripts live together in `scripts/` and should be run in numbered order.
- R imports use `janitor::clean_names()` so source names are lower case with underscores.
- School ID variables are stored as character variables in R and exported safely for Stata.

## DLP and Evaluation Data

The base DLP school-level file is:

```text
raw/Final_DLP_Dataset_for_Randomization.csv
```

The evaluation file is:

```text
raw/DLP_randomized_schools_eval.csv
```

The evaluation file is joined by `beis_school_id` to bring in `randomized_eval_id` and `rev_status`. The `rev_status` field is used as the main subgrouping variable for PI-facing descriptive statistics.

Rows are excluded from the analytic file when any of these key school fields are missing, blank, or literal `"NA"`:

- `beis_school_id`
- `region_code`
- `division_code`
- `full_division_code`

Excluded rows are saved to:

```text
outputs/validation_na_schools/01_schools_with_missing_key_fields.csv
```

## Merge Key

The school-level merge uses:

- DLP: `beis_school_id`
- Phil-IRI/RMA: `school_id`

Merge diagnostics are saved to:

```text
outputs/tables/01_merge_diagnostics.csv
```

## Phil-IRI Notes

Phil-IRI score outputs use Grades 7 to 10 English assessed counts as denominators.

The BoSY file includes English reading category columns with 2-level and 3-level groupings. The EoSY file uses reading category columns without explicit 2-level or 3-level suffixes. To keep the output structure consistent across time points, EoSY counts are written under both level group labels.

Phil-IRI score outputs are:

```text
outputs/tables/02_philiri_scores_long.csv
outputs/tables/02_philiri_score_checks.csv
```

## RMA Notes

RMA score outputs use grade-level assessed counts as denominators. Proficiency groups are:

- not proficient
- low proficient
- nearly proficient
- proficient
- high proficient

RMA score outputs are:

```text
outputs/tables/02_rma_scores_long.csv
outputs/tables/02_rma_score_checks.csv
```

## Compliance Rule

Compliance is created before Stata export using the assignment flags and `rev_status`:

- Assigned `control` and `rev_status == 0`: compliant.
- Assigned `mainstream`, `shifting`, or `emergency` and `rev_status == 1`: compliant.
- Otherwise: non-compliant.

Assignment group is derived from:

- `pilot_ratio`: mainstream
- `pilot_shift`: shifting
- `pilot_cancel`: emergency
- all three flags equal to 0: control

If more than one assignment flag is equal to 1, the school is labeled `multiple flags`.

## Stata Outputs

The Stata-ready dataset is:

```text
data/03_dlp_rma_philiri_school_level_for_stata.dta
```

Stata tables and logs are generated by:

```text
scripts/04_descriptive_stats.do
scripts/05_compliance_checks.do
scripts/06_visualizations.do
```

The visualization script uses IPA graph styling and sets Georgia as the print font:

```stata
set scheme ipaplots, perm
graph set print fontface "Georgia"
```
