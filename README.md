# Data for Policy Portfolio

This repository includes a small selection of reproducible data analysis scripts and workflow examples from my Summer 2026 internship with Innovations for Poverty Action. The work focuses on descriptive statistics, reporting workflows, and survey response coding for policy research in education, migration, and consumer protection.

The original datasets are restricted or sensitive, so they are not included or linked here. Instead, this portfolio shares public-safe scripts, documentation, dummy data, aggregate outputs, and workflow structures to give a sense of the analysis and reporting work I contributed to.

## Projects

- `dlp-descriptive-stats/`: school-level descriptive statistics and reporting workflow for the DepEd Dynamic Learning Program pilot.
- `deped-data-management-tutorial/`: dummy-data tutorial for survey data management checks, with Stata scripts and an R teaching analogue.
- `esc-shs-vp-targeting-descriptive-stats/`: high-frequency checks and school-level targeting summaries for ESC and SHS Voucher Program survey data.
- `esc-shs-vp-targeting-response-coding/`: open-ended response coding workflow for ESC and SHS Voucher Program survey responses.
- `investment-fraud-philippines-descriptive-stats/`: descriptive Stata workflow and aggregate output for an investment-fraud research example.
