# Data for Policy Portfolio

This repository includes a small selection of reproducible data analysis scripts and workflow examples from my Summer 2026 internship with Innovations for Poverty Action. The work focuses on descriptive statistics, reporting workflows, and survey response coding for policy research in education, migration, and consumer protection.

The original datasets are restricted or sensitive, so they are not included or linked here. Instead, this portfolio shares public-safe scripts, documentation, dummy data, aggregate outputs, and workflow structures to give a sense of the analysis and reporting work I contributed to.
